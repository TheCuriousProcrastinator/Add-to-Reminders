**Privacy Policy - Add to Reminders**

Add to Reminders accesses the title and URL of the webpage you choose to save and, when you use the selection feature, the text you explicitly select.

This information is used only to create a reminder in Apple Reminders on your Mac.

The extension communicates with a locally installed macOS helper using Chrome's Native Messaging API. Website information and reminder data are processed locally on your device.

Add to Reminders does not send browsing data, webpage content, reminder data, or personal information to the developer or to third-party servers.

The extension uses Chrome local storage only for preferences and temporary state, such as your last selected Reminders list.

Add to Reminders does not sell user data, use user data for advertising, or share user data with third parties.
